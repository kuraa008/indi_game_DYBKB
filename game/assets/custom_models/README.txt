ПАПКА ДЛЯ ПОЛЬЗОВАТЕЛЬСКИХ 3D МОДЕЛЕЙ (CUSTOM MODELS)
═══════════════════════════════════════════════════════

Сюда можно добавлять любые свои 3D-модели в форматах:
- .glb (рекомендуемый, Blender glTF binary)
- .gltf
- .obj
- .tscn (сцены Godot)

КАК ЭТО РАБОТАЕТ В РЕДАКТОРЕ:
1. Положите файл модели в эту папку (res://assets/custom_models/).
2. При запуске Редактора (или полигона) они автоматически появятся в каталоге [Tab] в категории «🎨 Мои модели»!
3. Модели можно сразу выбирать, ставить в мир, вращать, перемещать, дублировать и удалять.
4. Созданный уровень сохраняется в MapForge JSON вместе с путями к вашим моделям.

АВТОМАТИЧЕСКАЯ ИНТЕРАКТИВНОСТЬ:
- Если в названии файла есть "door" или "дверь" (например, `door_wood.glb` или `iron_door.gltf`):
  -> Редактор и игра автоматически подключат механику заколоченной двери с ломом и ключом!
- Если в названии файла есть "crowbar" или "лом" (например, `rusty_crowbar.glb`):
  -> Модель автоматически станет подбираемым ломом!
- Если в названии файла есть "key" или "ключ" (например, `golden_key.glb`):
  -> Модель автоматически станет подбираемым ключом!
- Для всех остальных моделей автоматически создается точный 3D-коллайдер (CollisionShape3D) по ее габаритам!
