# Escape in Skinwalker

Хоррор от первого лица на Godot 4.7, снятый будто на старую VHS-кассету. Тебя запирают в тёмном доме, а по нему ходит двелер и лесоруб с двустволкой. Ищи выход, прячься и не шуми.

## Скачать последнюю версию

### [⬇ Скачать игру (release.zip)](https://github.com/kuraa008/indi_game_DYBKB/raw/main/game/release.zip)

Только для Windows. Ссылка всегда ведёт на последнюю сборку. Распакуй архив и запусти `release/Escape in Skinwalker.exe`.

**Не качай игру через зелёную кнопку Code → Download ZIP.** В таком архиве вместо игры лежит файл `.exe` размером 134 байта, и он не запустится.

## Как играть

- **Прячься.** В шкафу и под кроватью монстр может тебя не заметить.
- **Не шуми.** Монстр идёт на звук: шаги, двери, кашель и даже твой голос в микрофон.
- **Следи за плёнкой.** Чем ближе монстр, тем сильнее помехи на экране.
- **Смотри в зеркала.** В них отражается твой герой.

## Управление

| Кнопка | Действие |
|---|---|
| WASD | идти |
| Shift | бежать |
| C или Ctrl | присесть |
| Пробел | прыгнуть |
| ЛКМ или E | действие: двери, шкафы, записки, предметы |
| ПКМ | выбросить предмет |
| F | фонарик |
| Tab | рюкзак |
| 1–6 или колесо мыши | выбрать предмет |
| Колесо мыши, глядя на дверь | чуть приоткрыть дверь |
| G | бросить предмет, чтобы отвлечь монстра |
| H | сигнальная ракета |
| Q (зажать) | задержать дыхание |
| M | микрофон |
| Esc | пауза и список кнопок |
| F3 | качество графики |
| F4 | эффект VHS |

Геймпад тоже работает.

## Если игра тормозит

В меню «Настройки» поставь графику ниже или оставь включённым «Авто-качество». Там же настраиваются звук, чувствительность мыши, VHS, разрешение и модели (РЕАЛИЗМ или РЕТРО).

## Как обновиться

Игра сама не обновляется. Если вышла новая сборка, в главном меню справа вверху появится кнопка «Вышло обновление». Она открывает ссылку на скачивание, после чего новую папку нужно распаковать вместо старой. Номер твоей сборки написан в меню справа внизу.

В версиях старше сборки 2 такой кнопки нет: их нужно один раз заменить вручную по ссылке выше.

Что менялось, написано в [CHANGELOG.md](CHANGELOG.md).

## Для разработчиков

Исходники лежат в папке `game`, проект открывается в Godot 4.7. Файл `.exe` хранится через Git LFS, поэтому перед `git clone` или `git pull` установи [Git LFS](https://git-lfs.com) и один раз выполни `git lfs install`. GitHub Desktop умеет работать с LFS сам: нажми Fetch origin, затем Pull origin.

Новая сборка выпускается так: увеличь `GAME_BUILD` в `game/scripts/Menu.gd` и число в файле `VERSION`, экспортируй Windows-версию и обнови `game/release.zip`.
