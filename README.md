# Escape in Skinwalker

Хоррор от первого лица на Godot 4.7.

## Скачать последнюю версию

### [⬇ Скачать игру (release.zip)](https://github.com/kuraa008/indi_game_DYBKB/raw/main/game/release.zip)

Ссылка всегда ведёт на последнюю сборку. Распакуй архив и запусти `release/Escape in Skinwalker.exe`.

**Не качай игру через зелёную кнопку Code → Download ZIP.** В таком архиве вместо игры лежит файл `.exe` размером 134 байта, и он не запустится.

## Как обновиться

Игра сама не обновляется. Если вышла новая сборка, в главном меню справа вверху появится кнопка «Вышло обновление». Она открывает ссылку на скачивание, после чего новую папку нужно распаковать вместо старой. Номер твоей сборки написан в меню справа внизу.

В версиях старше сборки 2 такой кнопки нет: их нужно один раз заменить вручную по ссылке выше.

## Для разработчиков

Исходники лежат в папке `game`, проект открывается в Godot 4.7. Файл `.exe` хранится через Git LFS, поэтому перед `git clone` или `git pull` установи [Git LFS](https://git-lfs.com) и один раз выполни `git lfs install`. GitHub Desktop умеет работать с LFS сам: нажми Fetch origin, затем Pull origin.
